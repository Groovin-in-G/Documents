Partition A Projects ≤ 60 MB · holds many Volumes

A partition is a category. This one holds finished tracks. Each Volume inside is a separate project.

A Volume contains all the programs and samples for one track. Loading a Volume swaps the whole project into RAM.

Key rules
  • One project = one Volume, not a Partition. Switch projects with DISK → LOAD VOLUME → 001 / 002 …
  • Partition cap: 60 MB (Akai filesystem limit). A partition is a category that holds many volumes.
  • S1100 RAM cap: 32 MB — a project fits inside a 60 MB partition with room to spare.
  • Files: samples = .S1, programs = .P1. Programs reference samples by name within the same Volume.
  • Sample prep before import: mono · 44.1 kHz · 16-bit · +0.1s trailing silence.
